# Product

<!-- impeccable:product-schema 1 -->

## Platform

android

## Stack

Flutter / Dart / Material 3. Firebase Spark metadata and consent-based push preferences; Supabase Free public list files; Python worker; Brevo hosted confirmed email subscriptions.

## Users and purpose

Philippine board-exam takers browse official PRC announcements and privately check a name against validated public lists. A matching name does not establish identity; an absent name does not establish exam failure.

## Constraints

No browsing signup, mandatory name entry, ratings access, extra dashboard, fictional runtime data, or simulated success. Names and outcomes stay on-device. Four destinations: Updates, Results, Check name, Settings. All exams in the official catalog; extraction only for validated supported formats. Initial Android Studio milestone precedes public deployment. Spend nothing; do not enable billing.

## Evidence

Authoritative spec and implementation plan copied to docs/superpowers. Empty repository at start of implementation. No PRC retrieval or provider setup performed. Physical device and live-service evidence must be reported separately.

## Accessibility

48 dp targets, TalkBack, 200% text, complete wrapping names, Android Back, keyboard and landscape support.
